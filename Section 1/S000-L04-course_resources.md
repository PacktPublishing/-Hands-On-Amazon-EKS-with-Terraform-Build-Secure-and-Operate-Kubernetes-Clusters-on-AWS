## Repositories

Each part of the course has its own, and the prefix tells you which part a repository belongs to.

- **[EKS Foundations]** [Starter Code](https://github.com/lm-academy/eks-foundations-starter): what you clone to build the cluster yourself, one section at a time.
- **[EKS Foundations]** [Complete Code](https://github.com/lm-academy/eks-foundations-solution): my finished version of the foundations sections, to compare your work against.
- **[EKS Access Management]** [Complete Code](https://github.com/lm-academy/eks-access-management): one repository holding **both the starting point and my finished code for those sections.**

More parts ship over time, and each one adds its repository to this list.
